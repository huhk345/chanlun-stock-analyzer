# 周线日线缠论 · 市场温度计

策略 ID：`chanlun-weekly-daily-thermometer`

## 设计层级

**周线 + 市场稳定趋势确认大势，日线只负责买卖点。**

- 周线只用**已完成周**（丢弃当前未完成周），避免未来数据。
- 周线大势：20 周均线方向（4 周斜率）+ 周线笔/中枢/买卖点，分为多头、底部确认、中性、熊市四档。
- 市场大势（“稳定”确认）：
  - 沪深300 同时站上 MA20、MA60；
  - MA20 > MA60，且 MA20 的 10 日斜率 > 0；
  - 大盘强弱评分 ≥ 50。
- 市场数据默认滞后 1 个交易日；超过 15 个自然日未更新时，回退到个股 MA20/MA60 趋势。回退期只允许周线多头中的 B3，仓位上限 25%，B1/B2 和大盘温度信号停用。
- 日线买点：
  - 买点必须先被**确认**：该买点所在笔之后已出现下一笔，笔的终点不会再被后续 K 线延伸改写。只有已确认的买卖点才与看板用完整数据算出的买卖点一致。
  - B3：确认后，收盘站上买点、日线 MA20 上方、当日收涨。
  - B2：同样要求确认，但**只在市场稳定趋势中启用**，避免弱市把下跌反弹误判为 B2。
  - B1：同样要求确认，且只在市场稳定趋势中启用。
  - 每笔买入都必须来自正式的 B3、B2 或 B1；优先级为 B3、B2、B1，B1/B2 只在市场稳定趋势中启用。
  - 买点确认后 `maxSignalAge` 个交易日内仍可入场（默认 10），超过则视为过期。
  - 周线未确认多头、日线 MA20 未上行或收盘未站上 MA20 时不买入。

## 温度与仓位

温度是**仓位和过热风控**，不是单独否决大势的开关。

| 温度 | 新开仓 | 条件 |
| --- | --- | --- |
| ≤25 冰点 | 100%（MA60 上方）/ 65%（MA60 下方） | 仍须满足周线多头及正式缠论买点 |
| 25–40 低估 | 80% / 50% | 主要买入区 |
| 40–55 中性 | 50% | 周线多头 + 稳定趋势 + 评分 ≥55 |
| 55–60 偏热 | 35% | 周线多头 + 稳定趋势 + 评分 ≥60 |
| 60–70 偏热 | 20% | 周线多头 + 稳定趋势 + 评分 ≥60，小仓跟随已确认买点 |
| ≥70 过热 | **不新开仓** | 已有持仓清仓 |

温度只决定"买多少"，不单独否决大势。早期版本用 `≥60 一律不新开仓`，导致
2025-09 至 2026-07 市场温度长期在 60–80 时整整一年零信号；现在 60–70 仍允许
20% 小仓顺势跟随已确认的缠论买点，只有 ≥70 才完全停止新开仓。

已有持仓：温度 ≥60 时，每个"入场温度 <60"的仓位只做一次 50% 减仓；>70 清仓。
60–70 建仓的 20% 小仓不再二次减半（否则次日就会被砍到 10%，风控形同虚设）。

其他关键默认值：

- 硬止损 10%，结构止损缓冲 1.5%。
- ATR 14 日、移动止盈倍数 5；最大浮盈达到 15% 后启动。
- ATR 保护触发时，如果周线仍多头，首次减仓约 50%，剩余仓位继续由周线、缠论卖点和结构止损管理。
- 最长持仓 60 根；收益 <2% 且周线多头未确认时才时间止损。
- 买入 RSI 上限 72；距 MA20 上限 12%；20 日相对强度下限 −8%。
- 最低日线买点评分 0.70。
- 卖出后冷却 0 根。

## 卖出

按优先级：

1. 市场温度 >70 清仓；≥60 每个仓位只做一次 50% 减仓。
2. 周线卖点或周线转弱清仓。
3. 结构/硬止损。
4. ATR 移动保护；周线仍多头时只减仓一次，周线未确认多头时清仓。
5. 日线 S2/S3 卖点。
6. 时间止损：达到最长持仓日数、按当日收盘对平均成本的收益不足门槛，且周线多头未确认。

周线转弱需要确认：已完成周线收在周 MA20 下方，且 4 周均线斜率不再向上。价格仍高于上行的周 MA20 时按回调处理；单独两根日线跌破 MA20 不平仓。

## 运行

```bash
# 重新生成市场数据模块
pnpm exec tsx scripts/build-market-strength-module.ts

# 回测
pnpm exec tsx scripts/backtest.ts \
  --strategy chanlun-weekly-daily-thermometer \
  --startDate 2021-01-01 \
  --endDate 2026-07-01 \
  --warmup 12 \
  --data data/hs300

# 策略专用核验 (真实历史条目、账本、前缀不变性、分时段诊断)
pnpm test:strategy:thermometer
```

市场数据来源：`data/external/market_strength_daily.csv`，生成模块：
`src/strategies/user/data/market-strength.ts`（4,586 行，2007-12-04 至 2026-10-20）。

这组结果没有证明策略存在正收益优势：七只股票合计 20 次买入，收益中位数在三个区间都不高于买入持有。该策略仍应视作研究版本；不能把回测或严格信号条件当作未来盈利保证。

本版本核验通过 347 项账本/信号检查和 4 个前缀不变性截断点。另将 601318.SH 的已知 B3 信号日期平移到市场数据末日后 30 天以上，验证市场温度源过期后策略仍以个股趋势回退发出 25% 仓位信号。

### 旧版回测结果 (严格 B1/B2/B3 入场之前，不代表当前版本)
